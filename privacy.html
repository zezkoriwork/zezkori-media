Privacy Policy

Last updated: 26 October 2026

zezkori publisher is an internal tool used only by the owner of the zezkori channels to upload videos the owner created to the owner's own Instagram and YouTube accounts.

Data we access

With the owner's authorization, the tool uses the YouTube Data API and the Instagram API only to upload videos and set their titles, descriptions and thumbnails, and to read basic statistics of the owner's own posts.

Data we store

Access tokens are stored as encrypted secrets in the owner's private GitHub repository. No data from other users is collected, stored, sold or shared.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google account permissions or in Instagram's Apps and Websites settings.
